# AI-901 Objective Checklist

## Microsoft Certified: Azure AI Fundamentals

This checklist is based on the Microsoft AI-901 study guide for the exam
objectives effective April 15, 2026.

An objective should only be checked when I can:

1. Explain the concept without relying on notes.
2. Recognize the concept in a scenario-based question.
3. Identify the appropriate Microsoft AI capability or service.
4. Complete a basic hands-on exercise when implementation is part of the
   objective.

---

## Identify AI Concepts and Capabilities — 40–45%

### Responsible AI

- [ ] Explain fairness considerations.
- [ ] Explain reliability and safety considerations.
- [ ] Explain privacy and security considerations.
- [ ] Explain inclusiveness considerations.
- [ ] Explain transparency considerations.
- [ ] Explain accountability considerations.

### AI Models and Configuration

- [ ] Explain at a high level how generative AI models work.
- [ ] Select an appropriate model based on required capabilities.
- [ ] Recognize deployment options and important model configuration parameters.

### AI Workloads

- [ ] Identify generative AI and agentic AI scenarios.
- [ ] Identify text-analysis scenarios.
- [ ] Identify speech AI scenarios.
- [ ] Identify computer-vision scenarios.
- [ ] Identify information-extraction scenarios.
- [ ] Explain keyword extraction.
- [ ] Explain entity detection.
- [ ] Explain sentiment analysis.
- [ ] Explain summarization.
- [ ] Explain speech recognition.
- [ ] Explain speech synthesis.
- [ ] Recognize computer-vision and image-generation capabilities.
- [ ] Recognize information extraction from text, images, audio, and video.

---

## Implement AI Solutions with Microsoft Foundry — 55–60%

### Generative AI Applications and Agents

- [ ] Create effective system and user prompts.
- [ ] Deploy a model and interact with it in Microsoft Foundry.
- [ ] Build a lightweight chat application with the Foundry SDK.
- [ ] Create and test a single-agent solution in Microsoft Foundry.
- [ ] Build a lightweight client application for an agent.

### Text and Speech

- [ ] Build a lightweight text-analysis application.
- [ ] Respond to spoken prompts using a deployed multimodal model.
- [ ] Build a lightweight application using Azure Speech in Foundry Tools.

### Vision and Image Generation

- [ ] Interpret visual input with a deployed multimodal model.
- [ ] Generate visual output with a generative model.
- [ ] Build a lightweight application with vision capabilities.

### Information Extraction

- [ ] Extract information from documents and forms with Content Understanding.
- [ ] Extract information from images with Content Understanding.
- [ ] Extract information from audio and video with Content Understanding.
- [ ] Build a lightweight information-extraction application.

---

## Week 2 Focus

The Week 2 work directly supports these objectives:

- Text-analysis workload identification
- Entity detection
- Sentiment analysis
- Summarization
- Speech recognition
- Speech synthesis
- Distinguishing generative AI, NLP, speech, retrieval, and agents

Do not mark an objective complete simply because the associated Microsoft
Learn module has been completed. Mark it complete when the concept can be
explained and applied independently.
