
# Secure Enterprise AI Assistant

This repository documents my six-month AI certification and enterprise AI-agent development project.

## Project Goal

Design and build a secure enterprise AI assistant capable of finding organizational information, explaining answers with citations, and eventually performing explicitly authorized actions.

## Certification Roadmap

This project accompanies preparation for:

- Microsoft Azure AI Fundamentals
- Microsoft Applied Skills for AI agents
- PMI Certified Professional in Managing AI
- Microsoft Azure AI Apps and Agents Developer Associate

## Project Status

**Week 3 — Vision, Information Extraction, and RAG**

Current work includes:

- Documenting the initial RAG architecture.
- Creating a synthetic enterprise knowledge base.
- Demonstrating manual retrieval using enterprise documentation.
- Constructing grounded responses supported by source citations.

The initial RAG design establishes the conceptual process for document ingestion, chunking, indexing, retrieval, and answer generation.

Automated retrieval, AI model integration, and production AI services have not yet been implemented.
