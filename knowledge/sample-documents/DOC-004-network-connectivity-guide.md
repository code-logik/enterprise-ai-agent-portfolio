
# DOC-004 — Network Connectivity Guide

**Organization:** Northstar Demo Manufacturing  
**Document Type:** Technical Guideline  
**Classification:** Internal Training  
**Version:** 1.0

## Purpose

Define the initial information-gathering process for suspected network connectivity issues.

## Initial Assessment

When an employee reports a network connectivity issue, the following information must be collected:

- Affected device or application.
- Approximate time the issue began.
- Whether the issue is intermittent or continuous.
- Relevant network or application error messages.
- Other systems experiencing similar symptoms.

## HMI and PLC Communication

If an HMI reports a PLC communication issue, the employee must record the observed symptoms and notify the designated technical support team.

Changes to PLC configurations, IP addresses, routing, and firewall settings must not be performed without authorization.

## Escalation

Unresolved network connectivity issues must be escalated through the approved technical support process.

If the incident affects production operations, the employee must also follow DOC-002, the Technical Incident Reporting Procedure.
