
# Enterprise Knowledge Base

## Purpose

This directory contains the knowledge sources used by the Secure Enterprise AI Assistant.

The initial knowledge base consists of synthetic enterprise documents created for AI architecture and retrieval exercises.

These documents are fictional training material and do not represent actual company policies or production operating procedures.
